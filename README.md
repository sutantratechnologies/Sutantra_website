## 🌟 Overview

Welcome to the official repository for **Sutantra Technologies**. This application is built with **Next.js (App Router)** and optimized for high-speed edge delivery, smooth UI animations, and modular scalability. It powers our core client-facing platform, developer tools, and service showcases at [sutantratechnology.com](https://sutantratechnology.com).

## 🚀 Getting Started

Follow these instructions to set up the development environment locally on your machine.

### Prerequisites

Make sure you have Node.js installed (version 18.x or higher recommended):
* [Node.js](https://nodejs.org/)
* npm, yarn, pnpm, or bun

### Installation & Local Development

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/ashokrimal/sutantratechnology.git](https://github.com/ashokrimal/sutantratechnology.git)
   cd sutantratechnology

 * Install dependencies:
   npm install
# or
yarn install
# or
pnpm install

 * Run the development server:
   npm run dev
# or
yarn dev
# or
pnpm dev

 * Open the app:
   Open http://localhost:3000 in your browser to view the application. The page auto-updates as you edit files under the app/ directory.
📂 Project Structure
├── app/                  # Next.js App Router (pages, layouts, and components)
├── public/               # Static assets (images, logos, icons)
├── styles/               # Global styles and Tailwind configurations
├── package.json          # Dependencies and script definitions
└── README.md             # Project documentation

🌐 Deployment
This application is deployed and hosted on Vercel, linked directly to our custom domain.
 * Production URL: https://sutantratechnology.com
 * Hosting Platform: Vercel
To deploy updates manually via CLI:
npx vercel --prod
